# claude

A sandbox repository for testing the capabilities of Claude Code.

## What's here

This repo is a place to try things out, so expect small experiments rather
than a finished project.

## How changes get made

Changes arrive as **pull requests (PRs)**. A PR proposes changes on a separate
branch and shows exactly what will change, line by line. Nothing lands on
`main` until someone reviews it and clicks **Merge**, and a PR can be closed
without merging if the change isn't wanted.
